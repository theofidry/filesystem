## Contributing

The project provides a `Makefile` in which the most common commands have been
registered such as fixing the coding style or running the test.

```shell
# Print the list of available commands
make
# or
make help
```

You can also execute this project within a [Docker Sandbox]:

```shell
sbx run claude --kit=.sbx/otel --kit=.sbx/project
```


[Docker Sandbox]: https://www.docker.com/products/docker-sandboxes/
